# 🚀 HyperBoost PC - Painel de Otimização Inteligente

O **HyperBoost PC** é um software avançado de otimização de sistema desenvolvido para limpar arquivos mortos, acelerar a resposta do Windows, estabilizar a rede e liberar o máximo de desempenho do seu hardware com apenas um clique.

---

### ✨ O que o HyperBoost PC faz?
O sistema executa um protocolo automático dividido em **10 etapas inteligentes**:

1. **Varredura de Temporários:** Remove lixo acumulado pelo usuário.
2. **Limpeza de Cache do Windows:** Específico para pastas temporárias do sistema.
3. **Otimização de Prefetch:** Acelera o carregamento de aplicativos.
4. **Limpeza do Windows Update:** Remove pacotes obsoletos de atualizações.
5. **Redução de Latência (DNS):** Limpa rotas de rede para melhorar o ping.
6. **Alocação de RAM:** Descarrega processos fantasmas da memória.
7. **Desempenho Máximo:** Força o perfil oculto de energia máxima do Windows.
8. **Bloqueio de Telemetria:** Encerra serviços ocultos de fábrica que consomem CPU.
9. **Limpeza de Lixeira:** Esvazia arquivos mortos de todos os discos.
10. **Fluidez do Explorer:** Sincroniza a estabilidade gráfica do sistema.

---

### 📥 Como Usar
1. Baixe o arquivo executável do programa na aba de **Releases**.
2. Clique com o botão direito no programa e selecione **"Executar como Administrador"**.
3. Acompanhe o painel de otimização rodando as 10 etapas e aproveite seu PC acelerado!
